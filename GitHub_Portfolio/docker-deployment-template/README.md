# 🐳 Docker Deployment Template

## 🎯 Descripción
Templates y configuraciones Docker para despliegue rápido de aplicaciones Python/FastAPI, basados en mi experiencia desplegando en RHEL8 con nginx y Openshift en Santander.

## 🛠️ Stack Tecnológico
- **Docker** | **Docker Compose** | **nginx** | **Redis** | **PostgreSQL**
- **GitHub Actions** | **Kubernetes** | **Openshift**

## 🚀 Templates Incluidos
- ✅ **FastAPI + PostgreSQL** - API con base de datos
- ✅ **nginx Reverse Proxy** - Configuración de proxy
- ✅ **Multi-stage builds** - Optimización de imágenes
- ✅ **Health checks** - Monitoreo de contenedores
- ✅ **Secrets management** - Gestión segura de credenciales

## 🎨 Escenarios Cubiertos
- **Desarrollo local** - Docker Compose para developers
- **Staging** - Configuración de pruebas
- **Producción** - Setup enterprise-ready
- **CI/CD** - Pipelines automatizadas con GitHub Actions

---

**💡 Basado en:** Experiencia real desplegando aplicaciones Django/FastAPI en infraestructura Santander
