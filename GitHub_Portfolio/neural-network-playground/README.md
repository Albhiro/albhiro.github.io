# 🧠 Neural Network Playground

## 🎯 Descripción
Playground de redes neuronales con ejemplos prácticos, desde perceptrones básicos hasta arquitecturas más complejas. Basado en mi experiencia investigando redes de redes neuronales.

## 🛠️ Stack Tecnológico
- **Python 3.9+** | **TensorFlow** | **PyTorch** | **numpy** | **matplotlib**

## 🚀 Ejemplos Incluidos
- ✅ **Perceptrón simple** - Clasificación binaria
- ✅ **MLP** - Multi-layer perceptron
- ✅ **CNN básica** - Reconocimiento de imágenes
- ✅ **RNN simple** - Secuencias temporales
- ✅ **Autoencoder** - Reducción de dimensionalidad

**💡 Inspirado en:** Mi investigación personal en arquitecturas de redes neuronales interconectadas
