# 🧠 NLP Spanish Basics

## 🎯 Descripción
Herramientas fundamentales de procesamiento de lenguaje natural para castellano, inspiradas en mi investigación personal de motores conversacionales y análisis gramatical.

## 🛠️ Stack Tecnológico
- **Python 3.9+** | **NLTK** | **spaCy** | **transformers** | **pandas**

## 🚀 Funcionalidades
- ✅ **Tokenización** avanzada para castellano
- ✅ **Análisis gramatical** (sustantivos, verbos, adjetivos)
- ✅ **Detección de entidades** (personas, lugares, organizaciones)
- ✅ **Análisis de sentimientos** básico
- ✅ **Corrección ortográfica** automática

## 🎨 Casos de Uso
- **Análisis de documentos** corporativos
- **Clasificación automática** de textos
- **Extracción de información** de contratos/informes
- **Preparación de datos** para modelos ML
